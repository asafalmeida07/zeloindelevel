## Acessibilidade e Contraste
A cor Avivamento original (#E8731A) não possui contraste adequado (WCAG 4.5:1) para leitura de textos sobre fundos claros (branco ou off-white).
- **--pilar-avivamento**: #E8731A (usado para preenchimentos, gráficos, fundos)
- **--pilar-avivamento-texto**: #A84A09 (usado para textos, links, abas ativas, garantindo legibilidade > 5.0)

Outros pilares mantidos com código original pois o contraste atende à métrica contra fundo claro.
